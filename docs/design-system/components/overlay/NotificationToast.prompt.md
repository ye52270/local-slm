한 줄: 급한 알림 하나를 오브 옆에 띄우는 320×84 말풍선 — 클릭하면 해당 항목이 패널에서 열립니다.

```jsx
<NotificationToast icon="mail" title="답장이 필요한 메일" message="박제영 · 배포 확인 건 · 오전 10:41" onClose={dismiss} />
```

- 한 번에 하나만. 여러 건이면 개수를 오브 옆 `SignalButton` 뱃지로 넘기고 토스트는 가장 급한 것만 씁니다.
- 제목은 무슨 일인지, 메시지는 왜 알리는지. 빈손일 때는 아무것도 띄우지 않습니다(빈손 침묵).
