한 줄: 실행 직전에 멈추고 허락을 받는 카드 — 거부하면 아무것도 실행되지 않습니다.

```jsx
<ApprovalBox
  verb="메일 발송"
  target="윤중식 · [월보] 2026-07 월간운영 보고 재발송"
  preview={"안녕하세요, 윤중식님.\n\n7월 월간운영 보고 관련 회신을 기다리고 있어…"}
  meta="외부 전송 없음 · 발송 후 되돌릴 수 없음"
  onApprove={approve} onReject={reject} />
```

- 색은 주의(warn) 계열. 헤더 문구는 "{동작} — 승인이 필요해요"로 고정.
- 승인 버튼만 ok 색, 거부는 중립. 버튼은 우측 정렬이며 가로를 꽉 채우지 않습니다.
- 여러 건을 한 번에 등록할 때도 건별로 카드를 띄웁니다.
