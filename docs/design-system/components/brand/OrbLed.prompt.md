한 줄: 데스크톱에 상주하는 얼굴 — 클릭하면 패널이 열리고, 창을 끌어다 놓으면 그 화면을 분석합니다.

```jsx
<OrbLed face="idle" onClick={toggle} />
<OrbLed face="clock" busy title="작업 중" />
<OrbLed face="mail" title="새 메일 1건" />
```

- 표정 6종(눈)과 신호 7종(스프라이트)은 같은 21×16 그리드를 씁니다. 새 표정을 만들기보다 기존 것을 재사용하세요.
- 무지개 림(`busy`)은 작업 중·듣는 중에만. 평상시에는 패널과 같은 재질의 림입니다.
- LED 패널은 항상 검정(`--led-panel` #0B0C0F) — 라이트 테마에서도 얼굴이 읽히게 유지합니다.
- 알림 개수는 오브에 숫자로 얹지 않고 입력창의 `SignalButton`으로 냅니다.
