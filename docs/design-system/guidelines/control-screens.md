# 파일·브라우저 제어 화면 (계획 · 실행 · 결과 · 권한)

몰두봇이 Outlook을 **읽고 추천만** 하던 단계에서, 사용자의 파일과 브라우저를 **직접 실행**하는 단계로 넘어갈 때
필요한 화면 4종의 명세입니다. 시각 재현은 `ui_kits/desktop-panel/Control.jsx` 에 있습니다.

## 승인 모델 — 위험한 것만

매 단계 승인을 받지 않습니다. 아래 분류대로 **자동**과 **승인 필요**를 나눕니다.

| 동작 | 기본값 |
|---|---|
| 파일 읽기 | 자동 |
| 파일 만들기 · 수정(새 파일) | 자동 |
| 브라우저에서 허용된 사이트 읽기 | 자동 |
| **기존 파일 덮어쓰기** | 승인 필요 |
| **파일 삭제** | 승인 필요 |
| **메일 발송** | 승인 필요 |
| **허용 목록 밖 사이트 열기** | 승인 필요 |
| 결제 · 구매 | 차단 |

이 기본값은 권한 화면에서 항목별로 바꿀 수 있습니다.

## 1. 계획 확인 (`plan`)

실행 전에 무엇을 할지 보여주고 승인받습니다.

- 사용자 발화 한 줄 → 몰두봇 답 한 줄 → 계획 카드.
- 계획 카드 안에 단계 목록. 각 행: `번호(모노 10.5px)` · `아이콘 14px` · `내용(1줄 말줄임)` · `우측 태그`.
- 우측 태그는 자동이면 `자동`(모노, `TextFaintBrush`), 승인 필요면 `승인 필요` 배지
  (`StateWarnBrush` 글자 + `TintWarnBrush` 배경 + 방패 아이콘 `\uEA18`).
- 행 배경 `SurfaceItemBrush`, 테두리 `BorderDefaultBrush`, 라운드 10, 패딩 8/10, 간격 6.
- 카드 하단 요약 한 줄: `파일 3개 · 사이트 1곳 · 승인 필요 2건 · 예상 40초` (모노, `TextFaintBrush`).
- 버튼 한 줄: `실행`(Primary) · `권한 확인`(Panel) · `취소`(Text). 높이 28, 패딩 12/9, 라운드 10.

## 2. 실행 중 (`run`)

- 헤더 우측 카운터: `단계 3/5` (모노).
- 상태 줄 아이콘 + 문구 3종:
  - 진행 중 — `\uE72C` + "몰두봇이 작업하고 있습니다" (`AccentDefaultBrush`)
  - 일시 정지 — `\uE769` + "일시 정지됨"
  - 승인 대기 — `\uE7BA` + "승인을 기다리는 중" (`StateWarnBrush`)
- 단계 목록은 계획 화면과 같은 행을 재사용. 상태만 다름:
  - 완료 → 번호 자리에 `\uE73E`, 행 전체 `Opacity 0.55`
  - 진행 중 → 테두리 `AccentDefaultBrush`, 배경 `AccentTintBrush`, 우측에 `진행 중`
  - 대기 → 그대로, 승인 필요 배지 유지
- 진행 막대: 높이 3, 라운드 2, 배경 `SurfaceItemBrush`, 채움 `AccentDefaultBrush`, 350ms 이징.
- 버튼: `일시 정지 / 이어서`(Panel, 승인 대기 중에는 비활성) · `중단`(Text) · 우측 끝에 현재 동작 종류(모노).
- **승인 게이트**는 목록 아래 별도 카드로 인라인 표시합니다. 새 창을 띄우지 않습니다.
  - 제목: `\uE7BA` + `덮어쓰기 — 승인이 필요해요` (`StateWarnBrush`)
  - 대상: 해당 단계 문구 그대로
  - 되돌림 안내: `\uE7A7` + "이전 파일은 30일간 보관 · 되돌릴 수 있음" / 발송이면 "발송 후 되돌릴 수 없음"
  - 버튼: `건너뛰기`(Panel) · `승인`(Primary)
- 승인 대기 중에는 타이머가 멈춥니다. 자동으로 진행하지 않습니다.

## 3. 결과 · 되돌리기 (`result`)

- 헤더 우측: `변경 3`.
- 요약 한 줄: "5단계를 마쳤습니다. 파일 2개를 바꾸고 메일 1건을 보냈습니다."
- `바뀐 것` 섹션에 항목 행. 각 행: 아이콘 · 제목 · 메타 · 우측 액션.
  - 되돌릴 수 있음 → `되돌리기` 버튼(`\uE7A7`). 누르면 행 `Opacity 0.5` + 메타가 `되돌림`으로 바뀜
  - 되돌릴 수 없음(발송 등) → `되돌릴 수 없음` (모노, `TextFaintBrush`)
  - 읽기만 함 → `읽기`
- 하단: `전체 되돌리기`(Panel) · `같은 작업 다시`(Text) · 우측 끝에 근거·시각(모노).

## 4. 권한 (`perm`)

- `폴더` 섹션 — 경로별 토글. 예: 바탕화면›월간보고(읽기·쓰기), 문서(읽기), 다운로드(차단됨).
- `사이트` 섹션 — 사내 위키, 그룹웨어, 그 외 사이트(열 때마다 승인).
- `동작` 섹션 — 항목별 3단 세그먼트: `항상 허용` / `승인 필요` / `차단`.
  - 항목은 승인표와 1:1로 맞춥니다: 파일 읽기(항상 허용) · **새 파일 만들기(항상 허용)** ·
    **기존 파일 덮어쓰기(승인 필요)** · 파일 삭제(승인 필요) · 메일 발송(승인 필요) ·
    외부 사이트 열기(승인 필요) · 결제·구매(차단). 새 파일과 덮어쓰기는 **분리합니다**.
  - 세그먼트: 배경 `SurfaceControlBrush`, 선택 항목만 `SurfacePlateBrush` + 그림자, 높이 20, 글자 11px.
- 토글: 34×19, 노브 14, 켜짐 `AccentDefaultBrush` + 흰 노브, 꺼짐 `SurfaceControlBrush` + `TextFaintBrush` 노브.
- 하단 안내 한 줄: `\uEA18` + "승인 필요 항목은 실행 중에 한 번씩 물어봅니다".
- 계획 화면에서 들어왔으면 상단에 `돌아가기`(`\uE72B`)를 두고, 누르면 **직전 계획 상태 그대로** 복귀합니다.

## 저장

- 위치: `%LOCALAPPDATA%\WinOrbPoc\permissions.json`
- 없거나 깨진 JSON은 위 기본값으로 복구합니다. 저장은 임시 파일을 거쳐 교체합니다.
- 이 설정 JSON 쓰기는 허용됩니다. 이번 범위에서 금지하는 것은 **사용자 업무 파일**의 읽기·수정입니다.

## 상태와 전이

진입점은 `/control-demo` 슬래시 명령입니다. 고정 데모 데이터로 계획 화면을 엽니다.

| 지점 | 다음 |
|---|---|
| 계획 · 실행 | 실행 중 |
| 계획 · 권한 확인 | 권한 |
| 권한 · 돌아가기 | 직전 계획 상태 |
| 계획 · 취소 | 에이전트 홈 |
| 실행 · 일시 정지 / 이어서 | 타이머 정지 / 재개 |
| 승인 필요 단계 도달 | 타이머 정지 + 인라인 승인 카드 |
| 승인 / 건너뛰기 | 해당 단계 상태 갱신 후 다음 단계 |
| 실행 · 중단 | 완료된 단계까지만 반영한 결과 |
| 전 단계 완료 | 결과 |
| 결과 · 같은 작업 다시 | 전 단계 초기화 후 계획 |

- 되돌리기는 이번 단계에서 **UI 상태만** 바꿉니다. 실제 파일에 접근하지 않습니다.
- 더미 진행 간격 1.1초. 승인 대기·일시 정지에서는 타이머를 완전히 멈춥니다.
- 화면 교체·취소·중단·패널 종료 시 타이머와 이벤트를 해제합니다.

## 모델

- `ControlActionKind` — 새 파일 만들기와 기존 파일 덮어쓰기는 **서로 다른 값**입니다.
- `ControlStepStatus` — `Pending` `Running` `WaitingApproval` `Completed` `Skipped`
- `PermissionPolicy` — `AlwaysAllow` `RequireApproval` `Blocked`

## 새로 필요한 아이콘 (Segoe Fluent Icons)

| 자리 | 코드 |
|---|---|
| 폴더 | `\uE8B7` |
| 파일 | `\uE7C3` |
| 새 파일 | `\uE8E5` |
| 브라우저 · 사이트 | `\uE774` |
| 실행 | `\uE768` |
| 일시 정지 | `\uE769` |
| 중단 | `\uE71A` |
| 되돌리기 | `\uE7A7` |
| 잠금 · 권한 | `\uE72E` |
| 계획 목록 | `\uE9D5` |
| 진행 스피너 | `\uE72C` |
| 돌아가기 | `\uE72B` |

두 개는 공식 명칭과 다른 용도로 **의도적으로 재사용**합니다:
`E8E5`는 공식 `OpenFile`이지만 새 파일 표시에, `E72C`는 공식 `Refresh`이지만 실행 중 회전 아이콘에 씁니다.
회전시킬 경우 VDI 성능을 고려해 최대 10fps로 제한합니다.

## 지키는 것

- 새 색을 만들지 않습니다. 위 브러시는 전부 `Themes/Dark.xaml` 에 이미 있습니다.
- 빨강 `StateUrgentBrush` 는 이 화면들에서 쓰지 않습니다. 승인·주의는 전부 `StateWarnBrush` 입니다.
- 실행 중에는 항상 멈출 수 있어야 합니다.
- 되돌릴 수 없는 동작은 승인 카드와 결과 목록 **양쪽에** 그렇게 적습니다.
- 패널 크기(약 560px)와 기존 레이아웃 규칙을 그대로 씁니다.
