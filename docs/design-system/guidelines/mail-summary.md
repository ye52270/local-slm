# 메일 요약 화면

`현재 메일 요약해줘` 응답 화면입니다. 시각 재현: `ui_kits/desktop-panel/Summary.jsx`

## 지금 무엇이 잘못됐나

1. **보낸 사람이 "Outlook"** — 애플리케이션 이름이지 발신자가 아닙니다. 실제 사람 이름을 넣습니다.
2. **원문 헤더 덤프** — `From:` `Sent:` `To:` 와 메일 주소 전체, 구독취소 URL이 본문에 그대로 나옵니다.
3. **요약이 없음** — 메일의 메타데이터만 나열하고 내용 요약이 없습니다.
4. **다음 동작이 없음** — 읽고 나면 끝입니다.

## 구조

```
사용자 발화 한 줄
카드
  ├ 킥      "메일 요약"  (아이콘 + AccentDefaultBrush)
  ├ 제목    메일 제목 15px/600, 최대 2줄
  ├ 메타    보낸사람 · 팀 | 받는 사람 N명 | 받은 시각(모노)   ← 한 줄, 11.5px, TextFaintBrush
  ├ 요점    • 3개 이내, 13px, SecondaryTextBrush
  └ 버튼    답장 초안(Primary) · 원문 열기(Panel) · 나중에(Text)
원문 발췌   접힘. 펼치면 SurfaceItemBrush 박스에 2~3문장
```

## 규칙

- **원문 헤더를 본문에 넣지 않습니다.** `From:` `Sent:` `To:` `Cc:` 줄, 메일 주소, `구독 취소`,
  `https://outlook.office365.com/...` 같은 링크는 요약에서 전부 제거합니다.
- 보낸 사람은 **사람 이름**입니다. 계정·앱 이름(`Outlook`, `noreply`)이 잡히면 원문 `From:` 에서 이름을 뽑습니다.
- 수신자는 나열하지 않고 `받는 사람 3명` 으로 셉니다. 이름이 필요하면 원문 열기로 갑니다.
- 요점은 **3개까지**입니다. 메일이 짧으면 1~2개로 끝냅니다. 없는 내용을 만들지 않습니다.
- 요약에 넣을 내용이 정말 없으면 요점 대신 한 줄로 적습니다: "조치 요청이 없는 공지입니다."
- 원문은 기본 접힘. 펼쳐도 2~3문장까지만 보여주고 나머지는 원문 열기로 넘깁니다.
- 시각은 모노, `08-14 14:06` 형식. 연도는 올해면 생략합니다.
- 새 색을 쓰지 않습니다. 이 화면에 상태색(빨강·노랑)은 등장하지 않습니다.

## 프롬프트 쪽에서 고칠 것

요약 품질은 UI가 아니라 프롬프트 문제입니다. 요약 프롬프트에 다음을 넣습니다.

- 메일 헤더 블록과 서명·면책 문구·구독취소 링크는 요약 대상에서 제외한다.
- 출력은 요점 3개 이내. 각 요점은 한 문장.
- 원문에 없는 내용을 추론해 넣지 않는다.
- 조치 요청이 있으면 첫 번째 요점에 둔다.
