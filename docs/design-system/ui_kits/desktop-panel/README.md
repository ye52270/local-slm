# UI 킷 — 데스크톱 상주 패널

몰두봇 데스크톱 앱(플로팅 런처)의 화면 재현 + 개선안. 원본: `ye52270/moldubot3` `desktop/`,
명세: `docs/design/06-ui-spec.md`.

## 화면
| 화면 | 상태 | 내용 |
|---|---|---|
| 접힘 | `bar` | 런처 520×88, 완전 알약. 입력 + 신호 아이콘(메일/알림) + ⌥Space 힌트 |
| 오늘 업무 | `brief` | 아침 브리핑. 추천 액션 1건 승격 + 다른 항목 + 오늘 일정/할 일 2열 |
| 진행 보고 | `chat` | 요약 나레이션 → 관련 메일 카드 3건 → 추천 칩 → 작업 과정(접힘) |
| 초안 작성 | `focus` | 좌 대화 / 우 작업물 패널(답장 초안). 폭 840으로 확장, 입력창에 포커스 태그 |
| 승인 | `approve` | 승인 게이트. 대상·본문 미리보기·되돌림 여부 → 승인/거부 |
| 계획 확인 | `plan` | 파일·브라우저 제어 계획 5단계. 위험 단계에만 '승인 필요' 표시 → 실행 |
| 실행 중 | `run` | 단계별 진행 + 진행 막대. 위험 단계에서 멈추고 인라인 승인 → 일시정지/중단 |
| 결과 | `result` | 바뀐 것 목록. 항목별 되돌리기, 되돌릴 수 없는 것은 명시 |
| 권한 | `perm` | 폴더·사이트 허용 스위치, 동작별 항상 허용/승인 필요/차단 |

테마 토글: 라이트(기본) / 다크(글래스). 같은 컴포넌트, CSS 변수만 교체합니다.

## 규칙
- 타이핑하는 곳은 메인 입력창 하나. 우측 패널은 작업물 전용(보기 + 결정 버튼) — 06-ui-spec §7.
- 카운트 뱃지는 무채색, 빨강은 '즉시 조치 1건'에만 — `--badge-neutral` / `--urgent`.
- 추천 칩 중 첫 번째만 accent, 나머지는 중립.
- 쓰기 동작(발송·등록·저장)은 반드시 승인 카드를 지나갑니다.
- 제어 작업은 **위험한 단계만** 멈춥니다 — 읽기·새 파일 만들기는 자동, 덮어쓰기·삭제·발송·외부 사이트는 승인.
- 실행 중에는 항상 멈출 수 있어야 합니다(일시 정지 / 중단). 끝난 뒤에는 무엇이 바뀌었는지와 되돌리기를 보여줍니다.
- 되돌릴 수 없는 동작은 승인 카드와 결과 목록 양쪽에 그렇게 적습니다.
- 라벨에 마침표·느낌표 없음. "성공적으로" 류 금지 → "메일 발송됨".

## 파일
- `index.html` — 인터랙티브 데모(테마·화면 전환)
- `Panel.jsx` — 런처 셸, 컴포저, 오브, 화면 4종
- `Control.jsx` — 파일·브라우저 제어 화면 4종(계획·실행·결과·권한)
- `panel.css` — 킷 스타일. 색·라운드·간격은 전부 루트 `styles.css` 토큰 기준
